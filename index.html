Selected work

Each repository leads with what the experiments showed, including the results that contradicted the method, and ships the full report with the code.

Atomic Visual Entailment

Master's thesis. Decomposing hypotheses into atomic facts so frozen vision-language models can be checked claim by claim, with no fine-tuning and no API cost.

Zero-shot accuracy on SNLI-VE improved by 12–25 percentage points over prior zero-shot and hybrid methods.

Reading analog clocks with CNNs

Five ways of representing clock time for the same convolutional network on the same 18,000 images.

Changing only the output representation moved error from 182.93 minutes — chance — to 8.52. The most precise-looking formulation was the worst.

Reinforcement learning on CartPole

Three studies covering DQN variants, policy gradient methods and PPO with GAE, implemented from scratch.

PPO's advantage turned out to be variance rather than ceiling — A2C reaches the same peak and cannot hold it.

Distributed video processing on Azure

Five queue-coordinated microservices splitting, watermarking, thumbnailing and reassembling video in parallel.

A fire-and-forget messaging pattern with a central aggregator, avoiding lock contention across services.

Hybrid recommender under extreme sparsity

Item-kNN, sequential co-occurrence, TF-IDF and popularity blended for Amazon beauty products.

Built for a dataset where 93% of users have a single interaction, which defeats collaborative filtering alone.

Landmark shortest-path estimation

Approximate shortest-path distances in large graphs, comparing landmark selection strategies.
