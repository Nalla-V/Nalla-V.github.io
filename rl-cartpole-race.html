DQN, A2C and PPO on CartPole-v1

Each agent starts from randomly initialised weights and trains for 250,000 environment steps. Training runs in this page. Nothing is loaded from a checkpoint and no request leaves the browser. The scheduler advances whichever agent has taken the fewest steps, so the horizontal axis below is experience, not compute time. Each cart is driven by its own policy at its current parameters. The algorithms are the ones from the repository, reimplemented in JavaScript with hand-written gradients.
